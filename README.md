## Built outside the classroom

- **A call system for a plumbing company.** When a call ends, AI writes it down, pulls out the address, job, urgency, price, and next step, and creates a deal in the CRM in under a minute. Twilio, Whisper, an LLM, and Pipedrive.
- **FinAid Dashboard.** Built with a university financial aid counselor. It adjusts the federal aid formula for regional cost of living and K-12 tuition, and shows each step of the math.

## How I work

1. Start with the job: what does the person need at the end?
2. Let AI draft. I decide.
3. Check it like a grader: facts against sources, every number and picture checked.
4. Build for the people using it: IEP versions for students, works on a phone, fits the systems people already use.
5. Leave the thinking to people: students still draw the graph and write the why.
